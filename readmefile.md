
# 🌱 BioBuddy - Plant Health Detective

Welcome to BioBuddy!

BioBuddy is a beginner-friendly Python project
that helps users explore possible reasons why
a plant may look unhealthy.

## ✨ Features

- Interactive questions about plant health
- Checks leaf appearance and soil moisture
- Considers sunlight and watering habits
- Provides possible explanations and care tips
- Simple Python code for beginners

## 🛠️ Technologies Used

- Python 3
- Basic conditional statements
- Functions and loops

## 🚀 How to Run

1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run the command:

   python main.py

## 🎯 Project Goal

The goal of BioBuddy is to explore how
simple programming logic can help organize
plant observations and suggest possible
next steps.

## ⚠️ Disclaimer

BioBuddy is an educational project.
Its suggestions are not a confirmed plant
disease diagnosis.
